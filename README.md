# School Management System

## Overview

The School Management System is a console-based application developed in C++ to manage and organize student and teacher records.

The project allows users to add, update, delete, search, and display student and teacher information. Student records include personal details, class, marks, average marks, and fee information. Teacher records include personal details, salary, classes, subjects, and joining information.

The system uses C++ structures for organizing data and binary file handling for storing records permanently. It also includes features such as marks calculation, pass and fail classification, fee calculation, number-to-words conversion, and teacher birthday notifications.

This project demonstrates the practical use of C++ concepts such as structures, functions, arrays, loops, conditional statements, file handling, searching, updating, and deleting records.

## Features

* Student record management
* Teacher record management
* Add, update, delete, and search records
* Display student and teacher records
* Student marks and average calculation
* Pass and fail classification
* Fee management
* Number-to-words conversion
* Teacher birthday notification
* Binary file storage
* Login system
